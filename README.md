# Virtual Switch — Operating Systems Fall 2026

A multithreaded software network switch written in C for Linux.

## Programs
- switch: the network switch server
- host: a test client
- swctl: the administration client, planned for Tier 2

## Current progress
Tier 1 implementation in progress.

## Build requirements
gcc -std=c11 -Wall -Wextra -Werror -g -O0
